# 第三方依赖登记

实际版本见 `package.json` 与 `package-lock.json`。本目录保存 React、React DOM、Three.js、Vite、TypeScript 和开发验收工具 html2canvas 随 npm 包提供的许可文件。

GSAP 3.15.0 的 npm 包通过 `package.json` 声明其标准许可链接：[GSAP Standard License](https://gsap.com/community/standard-license/)。本项目使用其程序动画 API。对应包没有单独 LICENSE 文件，因此这里保留官方直接入口；2026-09-30 已核查该页面。

正式构建不含 html2canvas 和开发验收面板。项目没有随包分发系统字体、馆藏照片、第三方采样或真人配音。
