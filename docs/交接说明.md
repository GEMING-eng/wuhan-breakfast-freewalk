## 素材登记

现行清单在 `src/content/assetManifest.ts`；磁盘资产的尺寸、字节与 SHA-256 在 `asset-files-v1.1.json`。`paper-art.json` 登记 SVG 纸偶身份、轮廓、尺寸与生产方法；验收 JSON 登记每件实际几何的类型、局部/世界位置、旋转、厚度、材质用途与交互 ID。

原始矢量美术可由 `node tools/create-paper-art.cjs` 重建。纸纹为程序绘制；印刷图案不含空间投影，侧边和影子来自三维几何与灯光。纸偶共六张图案，两种姿态/表情使用相同轮廓，避免切换时体积跳变。食物小札使用同一套图案。小凳本体为立体纸板结构，小札用 SVG 概括同一形态。

`legacy-art/asset-files-v1.json` 是旧制作阶段的登记，路径相对于当时的资产目录。旧图的“final”只表示旧图生产完成，不表示当前纸景正在使用它。旧生成提示保留为 `legacy-art/prompts-v1.json`。

## 内容与来源

S01—S05 的直接链接、发布机构、日期与使用范围见 `src/content/sources.ts`，正式页面也可以打开。饮食知识与剧情创作分开：店铺、人物、师承、街坊对白、相片留言均为创作。约 1980 年代是艺术情境范围，具体器具组合不作为精准年代复原。

字体使用系统中文字体，工程不分发字体文件。工程使用的第三方库许可文本随附于 `licenses/`；继续发布或扩展前应按对应库的许可处理。旧图为本项目内置图像生成工具产物，不含真实档案照片。

## 继续扩展的入口

调整纸面图案：`tools/create-paper-art.cjs` 和 `public/assets/`。修改纸层、折面和厚度：`PaperPart.ts`、`ShopBuilder.ts`。调整镜头：`cameraPresets.ts`；热点跟随三维锚点，不能改成固定背景图坐标。修改剧情：`story.ts`；完成条件由状态机控制。

网站通过本地静态服务运行。按用户要求，完整源码、必要素材与验收记录发布到公开 GitHub 仓库 `GEMING-eng/wuhan-breakfast-paper-stage`；v1.1.0 发布包附有现成构建和启动脚本。网页本身没有账号系统，也不上传体验者数据。后续可在同一工程内继续细化纸偶、门面与印刷纹理。
