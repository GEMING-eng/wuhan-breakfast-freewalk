# 过早旧影：绘本老街与可扩展铺位

日期：2026-10-03。此文是本轮画风变更与老街场景的交接入口，优先于 v3 中关于写实纸板/PBR 的美术建议。既有 v3 的今昔翻墙、旧物特写和人物局部表情逻辑继续保留。

**v7 优先：**当前入口是 `/?sample=tour&v=7`，采用自由选店；固定八站顺序已经取消。先读 [v7 交接](自由逛街-v7-交接.md)。本文保留基础街景/铺位的实现说明；涉及游客数量、现有店数、存档与故事接入，以 v7 为准：18 位游客，新增体验里豆皮/面窝占用两处旧预留铺位，还剩三处。新店接入 ExploreExperience，不接回旧的线性 StoryProvider。

## 用户最终选择

以 `style-reference.jpg` 为画风参考：细而清楚的暖灰线条、淡彩色块、青灰瓦、粉蓝墙、桃木色、豆绿植物；斜俯视、剖开的室内、密集而有秩序的日常细节。它是能走近的立体绘本。不要回到摄影感的整图、纯色低模或重度油亮的写实渲染。

建筑与人物仍是武汉早餐街的创作。参考图中的火锅楼、旅拍馆、水乡等内容不作为武汉史实或必须复制的业务内容。林记与这条街都是虚构场景，不能给生成图加上真实历史复原的标签。

## 从哪里看

- `/?sample=street`：新老街总览，五个镜头、纸偶路人、日出光线、周边住宅、庭院和预留铺位。
- `/?sample=noodle&art=storybook`：同一绘本风林记的独立精细样板。

Windows 双击根目录 `Start-Street.cmd`，使用已构建的 `dist/`。需 Node.js 22.18 或更新版本。4173 已占用时不要杀死未知服务；使用已有预览，或自行启动另一端口的 Vite 预览。开发时执行 `npm.cmd ci`、`npm.cmd run dev -- --port 5188`。

## 这一版包含什么

1. 连续石板主街、两侧人行道、路沿、排水沟与格栅、少量湿地反光、街尾歇脚庭院、两侧住宅小院、环绕的民居纸景和天空。
2. 六处两层建筑结构。楼上是有地板纵深、栏杆、灯、桌椅、杯碗和盆花的房间；面对镜头的侧墙剖开，让房间保持可见。双坡瓦顶、外楼梯、雨水管、藤蔓和晾衣线连接各家。
3. 一间完整林记，五处可替换的木门/竹帘铺位。后者只有环境围合，没有冒充已经完成的美食互动。
4. 菜摊、纸伞、自行车、坐凳、茶桌、花盆、路灯、电线，九位纸偶路人/游客，其中四位沿固定路线缓慢往返；另有轻摇的树木、衣物与两只纸鸟。
5. 真实三维方向光、随“晨光”滑杆变化的光色/高度和阴影。天空底图与环境围景采用生成插画。不是预渲染视频，也不是 Blender 离线光线追踪。
6. 林记保留四扇纸墙依次翻转 180°、雨棚抬起再落下、两代店主与室内陈设更换。纸面 UI 同步从旧日暖色变为今日豆绿色。
7. 店主、面碗、酱罐、小凳都有真正移动的特写镜头；面上有五缕持续变化的透明热气。人物是五种嘴型加独立眨眼，身体保持同一张底图。
8. v5 增加三个“街边小事”特写：茶桌（编竹暖瓶/收音机/搪瓷杯 → 保温杯/帆布袋/街巷手册）、菜摊（杆秤/纸包 → 电子秤/布袋）、留言板（两套情境纸条）。共用木桌和框架不换，时代物件围绕父组转动，杯上蒸汽在翻面中央淡出，结束后恢复。
9. 楼上补充六组折面窗帘、花架/碗柜、门牌与晾椒；路边增加 112 片零散落叶及 42 处小草。少数叶片轻轻移动，杆秤缓慢晃动，所有环境动态跟随“静一静”。

## 接入一家新店的顺序

1. 读本文件和 `src/street/layout.ts`，先选固定 id，不要为了放得下模型随意压缩道路。
2. 在独立店铺模块中按局部坐标搭建：地面 Y=0，+Z 为门面，核心范围 X=±4.7、Z=±2.6、Y=0…6.1。复用室外永久结构，不重复叠加楼房、路面或围墙。
3. 在 `MorningStreet.build()` 中，静态合批之前，用 `this.sockets.get(id)` 获得挂载点。移除其中名为 `removable-closure-${id}` 的临时门板组，再把新模型加到该 socket。
4. 临时门板组标记了 `userData.animationRoot=true`，因此不会被跨建筑的静态合批拆散。将来需要在运行时整体移除、替换、翻转或移动的组，都要设置这个标记，再调用合批。
5. 静态环境合批后，不要修改 socket 变换来移动整栋建筑；静态几何已经转换到场景坐标。调整布局数据后重建环境。运行时动画必须保留独立父组。
6. 为新店添加自己的角色、旧物、食物、两套年代资产、相机预设与文案。不能只给林记换一个名字。
7. 先做单店近看、翻墙、暂停与快速反向切换验收，再加入街景热点和原故事状态机。原来的“我的过早”、剧情进度、文化记忆仍由原 StoryProvider 管理，不要新造一套冲突的存档键。

示意（放在 build 合批之前，不是直接粘贴进现有作用域就能运行的完整模块）：

```ts
const socket = this.sockets.get('doupi')!;
socket.getObjectByName('removable-closure-doupi')?.removeFromParent();
const doupi = buildDoupiShop(workshop);
doupi.userData.animationRoot = true; // 店铺含翻墙/角色等独立动画
socket.add(doupi);
```

## 模块职责

| 文件 | 职责 |
|---|---|
| `src/street/StreetExperience.tsx` | 街景 React 界面、镜头选择、时代选择、音效、手记、铺位清单 |
| `src/street/MorningStreet.ts` | 环境生命周期、道路/楼房、行人路径、光照、五个漫游视角、店铺世界坐标转换 |
| `src/street/Neighborhood.ts` | 民居围景、庭院、手绘树、外楼梯、花盆、窗格、纸鸟 |
| `src/street/StreetProps.ts` | 菜摊、纸伞、自行车、长凳等实体小物 |
| `src/street/StreetLifeDetails.ts` | 三个生活角落的实体器物、两套年代陈设、窗帘/街边植物、同步翻面和环境小动作 |
| `src/street/moments.ts` | 三个生活角落的相机目标、距离与两套情境文案 |
| `src/atelier/SceneExtension.ts` | 单店引擎与街景环境的接缝 |
| `src/atelier/AtelierScene.ts` | 林记、人物表情、旧物镜头、今昔翻墙与动画生命周期 |
| `src/atelier/PaperWorkshop.ts` | 几何/贴图资源、纸片轮廓、六帧 atlas、静态合批、细线勾边 |
| `src/atelier/SceneFinish.ts` | 接触阴影、轻描边与线性色彩输出 |
| `src/atelier/Steam.ts` | 热气 shader，正确处理旋转后的店铺父坐标 |

共享资源统一由 PaperWorkshop 回收。背景、人物、蒸汽等特殊透明层通过 `noAO` 排除不合适的接触阴影。不要将整张 alpha 图片换成没有透明轮廓的方形卡片。不要合并有动画或需要替换的组。

`SceneExtension.update(time, camera, turn)` 的 `turn` 来自林记纸墙实际角度除以 π，不能使用环境时间来另起一套年代计时器。这样环境暂停、直接打开 `era=present` 和快速反向切换都能保持一致。每套陈设的父组独立保留，仅在父组内部合批；可剖开的侧墙也只在本墙内部合批，避免窗口和花盆失去显隐关系。

生活角落固定在未来铺位之外：茶桌中心 (7.25, 14.4)、菜摊 (-6.3, 13)、留言板 (-5.85, -25.5)，此处是 X/Z。近景镜头已经绕开路口大招牌；不要把菜篮镜头移回招牌背后。茶桌旁大树与小凳已错开路灯杆；修改位置后必须再看实际截图，不能只测中心距离。

## 美术资料及再生成

- 用户参考：`docs/street/style-reference.jpg`。
- 本轮 15 张生成原图：`docs/street/storybook-source/`。
- 运行时 WebP：`public/assets/storybook/`，合计约 6.4 MB。
- 完整提示词与生成来源：`docs/street/storybook-generated.json`；初始 12 张另存于 `storybook-prompts.json`。
- 所有图使用本次会话的内置 ImageGen 生成。没有在线图床依赖，没有把生成服务接入产品。
- `tools/prepare-storybook.cjs` 只复制原图并压缩 WebP，不做自动抠图改画。透明由生成工具输出，三维轮廓在运行时根据 alpha 生成。
- 较早的 `public/assets/street/` 与 `docs/street/source-art/` 是换画风前的探索，当前页面不加载。复刻时用 `storybook` 这一套，不要混回写实探索图。

人物 atlas 原图实际为 1254×1254，并非提示词要求的 1536。六个人物间距也不完全均匀。`portraitAtlas()` 记录了实测每帧像素偏移和嘴/眼局部遮罩；不要改成简单的等分切图轮播。替换 atlas 后必须重新校准，并验证嘴型变化之外脸和身体没有跳动。

统一画风准则：

- 线条约 1 个屏幕像素的视觉重量，暖灰而非死黑粗边。
- 木头以桃木/赭色淡彩与细线表现，不用照片木纹和油亮高光。
- 青灰瓦、蓝绿窗、粉蓝墙、米色纸面；旧日点缀灰红，今日点缀豆绿。
- 阴影保留物件接地关系，但不要用浓雾冲淡全图，不要靠大面积黑影制造“高级感”。
- 楼上从斜角能看见地板、桌椅和后墙；不能重新封回一个贴着图的方盒。
- 店招和交互文字由代码绘制/排版。生成图上的零碎文字不作为历史资料或关键界面文本。

## 验收与限制

浏览器报告及实际截图在 `docs/street/verification-final/`。执行 `node tools/verify-street.cjs` 需要 Playwright、Chromium 和 sharp；可以用环境变量 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`、`SHARP_MODULE` 指向已有安装。当前脚本使用 Windows D3D11，与本机 RTX 5060 Laptop GPU 的硬件渲染验收一致。

检查包括五个漫游镜头、行人运动/暂停、晨光像素变化、六个铺位清单、四个旧物特写、蒸汽、面碗间隙、暂停状态下翻墙、UI 年代同步、五嘴型与眨眼、快速切换、手机宽度、手记、减少动态偏好、单店与原故事入口。

`npm.cmd test` 包含原 22 项测试与新增 5 项铺位与可替换结构测试。手机已做 Chromium 390×844 布局模拟；未宣称在实体 iPhone/Android 上完成性能或音效验收。独立测试浏览器实际运行在桌面 GPU 上，不能把它的帧率写成手机帧率。

v5 新增验收脚本 `tools/verify-street-details.cjs`，报告/截图在 `docs/street/verification-details/`。它检查三个角落的特写、暂停时翻面、快速反向切换、UI 文案、直接进入今日、回街/进店，以及手机卡片与导航不重叠。它是对原有浏览器验收的补充。

第一版老街里的其他五家店未制作；当前今昔变化作用于林记、三个生活角落及对应 UI。外围民居和路人尚未全部按年代更换。未来若扩展整条街的年代差异，应把每栋外立面、街边交通/用品、人物衣着纳入独立的年代数据，不能只加滤镜。保留这条范围边界。
