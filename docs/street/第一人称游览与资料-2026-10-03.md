# v6：把绘本老街串成一次完整的过早游览

日期：2026-10-03。入口 `/?sample=tour&v=6`。这是可运行的实现说明，承接 v5 的细线淡彩立体绘本风格。街道与店铺结构沿用现有资产；新增第一人称步行、八站文化路线、进度恢复和个人手册。原街景总览、单店样板及原三店故事仍可访问。

## 体验顺序

点击“走进早市”开始；有进度时显示“接着上次的脚步”，完成后显示“打开我的过早记忆”。阅读一页后主动继续，站点之间沿街行走。用户可以左右拖动画面环顾，随时打开资料手册。步行时可“直接到达”，也可用“减少动态”直接切换停留点。

| 顺序 | 停留点 | 看到、了解到什么 | 完成动作 |
|---|---|---|---|
| 01 | 走进清晨 | 巷口长街、石板路、纸偶行人；说明游览方式 | 读完两页 |
| 02 | 武汉过早 | 菜摊前认识“过早”；从诗词与商埠生活理解早餐文化 | 读完两页，可查出处 |
| 03 | 林记一碗面 | 第一人称站在柜台前；店主表情、蓝花碗与动态热气；食物材料介绍 | 把热干面记进手册 |
| 04 | 手艺与来历 | 走近酱罐，认识轧面、掸面与调味；区分历史与起源传说 | 读完两页 |
| 05 | 同一店的今昔 | 相同位置对照两代店主、陈设、雨棚；四块墙板连续翻转 180° | 主动切到今日，等变化结束后继续 |
| 06 | 一街百味 | 街边实体食单；认识三鲜豆皮与面窝的形态、材料和器具 | 可再记下两种食物，继续阅读 |
| 07 | 街坊与日常 | 留言板前看街坊纸条，可再次对照今昔 | 读完两页 |
| 08 | 把清晨带走 | 到街尾回头望一眼来路 | 选择一段记忆，生成个人手册 |

共 15 页，阅读节奏由用户控制。介绍页区分“文化资料”“场景观察”和“虚构对白”。每一页事实介绍都关联具体资料；右上角手册可查阅全部五项来源。

结尾包括已选食物、记忆和资料入口，可下载 Markdown 手册。保存的是这个浏览器的本地进度，不含账号或云同步。浏览器不允许写入时会给出提示，游览与手册下载仍可使用。

## 第一人称镜头

- `FirstPersonWalk.ts` 固定眼高 Y=2.45 **场景单位**。这是本场景的视觉比例，不是现实测绘高度。
- 视线与站位分开；拖动只转头，不绕物体旋转身体。当前实现是八站引导式步行，没有 WASD 自由碰撞漫游。
- 跨较远停留点时先进入 X=0 的街道中央，再沿 Z 行走，最后靠近路边。站位保持在 |X|≤3.5 范围。新建筑或道具不应侵占这条路线。
- 短距离观察在相邻站位间移动。使用 GSAP 连续过场，无上下晃头；过场可跳过。减少动态后镜头直接到达，环境小动作暂停；用户主动触发的今昔翻墙仍保留。
- 桌面 FOV=64°，手机竖屏 FOV=86°；手机对面摊做少量取景调整，为下方卡片留出可见空间。手机采用画面上半部观察、下半部滚动阅读、固定底部操作的结构。
- `SceneExtension.view()` 的 `direct` 和 `fov` 是可选扩展。旧的街景与单店镜头不启用第一人称分支。

## 晨光与动态

方向光产生真实几何投影。随着路线推进，光源从较低位置缓缓抬升，颜色从橙金过渡到淡暖色；站点变化用 3 秒缓动衔接，不突然跳变。树影、电线和栏杆投影、湿石板的轻微反光、稀疏浮尘与食物热气共同表现早晨。

`MorningRays.ts` 增加三束带深度测试的柔和绘本光束，保留淡彩纸景风格。它是实时绘制的氛围层，并非体积光积分或离线路径追踪。场景已有接触阴影与细线勾边。

天空继续使用已有生成插画；延长背景几何并保持原地平线的贴图比例，修复宽视角抬头时看到圆柱顶部硬边的问题。行人、树叶、衣物和纸鸟沿用现有动态，不依赖视频。

今昔切换在相同停留位置进行，墙板、雨棚、人物与生活角落变化；界面纸色、印章与按钮在年代应用时同步更新。原有五处预留铺位仍为空间预留，未冒充已完成的新店。

| 文件 | 职责 |

| `tools/verify-tour.cjs` | 从入口真实点击走完整条路线的浏览器验收 |

新路线使用独立键 `wuhan-breakfast-story.tour.v1`。原 `/` 故事仍使用原键 `wuhan-breakfast-story.save.v1`。这是两种入口的进度隔离，不是同一进度的双写；不能把两个 JSON 结构互相覆盖。

进度至少包括站点、页码、最远可回看站点、已选食物、年代、已对照今昔、记忆选择及完成标记。坏 JSON、越界页码、无效食物、重复食物和互相矛盾的完成记录都不能恢复。开始新的游览只更新本路线键。

在本版本中，第 3 站必须记下热干面，第 5 站必须实际切到今日，最后必须选一段记忆，才会形成完整手册。已到过的站可从上方路线返回；未来站不提前开放。

## 验收与继续开发

先 `npm.cmd test`、`npm.cmd run build`。使用现成 `dist` 的本地预览不依赖 npm 安装，开发需要 Node.js 22.18+ 并执行 `npm.cmd ci`。

浏览器脚本需要可用的 Playwright 和 Chromium。可通过 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH` 指定本机路径，回归街景时额外提供 `SHARP_MODULE`；不要把此开发机路径写死进产品源码。

```powershell
node tools/verify-tour.cjs
node tools/verify-street.cjs
```

当前浏览器证据见 `verification-tour/`，共 22 项路线检查；共享街景回归见 `verification-final/`，共 23 项检查；状态和布局测试共 31 项通过。检查覆盖真实行走、只转头不绕物体、按页出处、收集和对照门槛、180° 动画、UI 换色、刷新继续、结尾下载，以及 390px / 320px 的手机布局。截图等待当前站位实际到达，不能仅凭卡片标题已经更新就拍图。

本机 Chromium / D3D11 桌面回归约 27.5 帧/秒，渲染循环上限 30 帧/秒。该数据不能代表实体手机性能。实体手机触摸/音频听感未实测；声音播放不自动开启。未经用户要求，不替换当前绘本风、不填满预留铺位、不发布到远端。

后续应先在这条游览路线加入新店的实际模型与专属观察环节，再按来源补内容。保留现有八站闭环的同时可调整站数；修改后同步更新上方进度总数、手册文案与测试，避免出现假完成。
