# v9 · 第一人称自由逛街

2026-10-04。当前入口为 `/` 或 `?sample=tour`，均使用 `ExploreExperience.tsx`。本文取代旧文档中的地图选店和跳过步行流程。

## 操作

进入封面后站在街道中央。电脑用 W/A/S/D 或方向键前后左右移动，拖动画面转向，滚轮调整视野；手机用左下摇杆移动、在街景空白处拖动转向，右下加减按钮缩放。点击铺面旁的按钮可沿街走近，也可以随时自己行走。打开店铺列表、食篮和资料手册时暂停行走输入。点击“继续走走”保留当前位置与视线，不切换俯视镜头。

## 这次变化

- 18 位行人整体放大，保持脚底贴地，并按年代更换形象与随身物品。
- 统一眼高相机；入口、步行、到店、换店与离店都使用第一人称。
- 豆皮铺使用独立的昔日/今日墙面、围裙、柜台陈设与动画人物；面窝摊新增两年代翻墙和不同厨房插画、灶具、招牌与容器。
- 六栋临街楼都参与年代变化：旧砖修补、门窗、墙面、门牌、店招、台基和维护状态同步变化。三个原预留铺面改为街坊书屋、巷里人家、邻里小院的可观察街坊门面。
- 老石板具有颗粒、裂纹、磨损、苔痕、车辙污渍及排水边石；今日路面使用修缮后的石板与补丁。自行车、收纳桶等街具也分两年代。
- 暂停环境动画后，移动、转向、缩放和今昔切换仍可操作。食篮保存与旧存档兼容。

## 代码与资源

`FreeWalk.ts` / `walkMath.ts` 负责移动与视线；`WalkJoystick.tsx` 负责触屏摇杆；`StreetEras.ts` 管理建筑及街具；`AgedPaving.ts` 绘制地面材质；`FoodStalls.ts` 管理面窝摊。年代翻转使用同一个进度，避免各处停在不同年代。

美术为虚构绘本场景；AI 素材记录位于 `v8-doupi-generated-assets.json` 和 `v9-generated-assets.json`。文化资料沿用项目资料手册，场景变化不代表特定历史年份的复原。

## 验证与实际范围

自动测试覆盖移动方向、斜向速度、街道边界、缩放范围、所有楼前停靠点与旧食篮兼容。浏览器验收记录与截图在 `verification-v9/`。桌面宽屏与手机尺寸通过浏览器模拟检查；尚未在实体手机上测量帧率或多指手势。

行走区域限制在街道内，店铺从柜台前交互；不支持穿入房屋后室或楼梯。面窝店主随年代换画，尚无独立嘴型动画。街坊书屋等三栋为可观察门面，未扩展成三家新的早餐制作关卡。
