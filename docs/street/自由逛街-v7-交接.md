# v7：自己选一家，走进去看看

2026-10-03。当前产品入口为 `/?sample=tour&v=7`；`v=6` 参数也会进入最新体验。用户明确取消固定八站推进，改为地图自由选择、第一人称走近、左侧食篮保存。本文优先于 v6 中有关顺序和解锁门槛的说明。

## 新交互

1. 封面是新生成的淡彩老街插画，网页标题、按钮和导航仍是 HTML。点击“去街上逛逛”进入地图。
2. 地图六个圆点分别通往林记热干面、豆皮铺、面窝摊、巷口菜摊、街坊留言和巷尾树下。所有地点从一开始开放，也提供同等功能的文字入口。
3. 点地点后切到行人眼高，沿安全路线步行过去。可以跳过步行，也可暂停环境动态。不存在上一家没看完就不能进入下一家的限制。
4. 店内文化介绍可翻页、合上、重新打开。林记可任意选“这一碗”“手艺与来历”“看今昔”，保持 180° 翻墙和原来的动态嘴型、眨眼、热气。
5. 食物到访后即可加入“我的过早”，无需看完介绍。左侧列表可以回看、移出、下载；刷新后仍保留。同一种味道不重复添加。
6. 手机左上食篮按钮展开侧栏，可通过明确的关闭按钮、外侧空白或 Escape 收起。资料出处在文化页可打开。

卡片、侧栏、按钮与弹窗使用圆角，昔日和今日分别使用暖纸色与淡绿色。食篮仅记录食物与文化记忆，不引入价格、付款或库存。

## 存档

当前键为 `wuhan-breakfast-story.explore.v1`。结构包括 `place`、`visited`、`foods`、`era` 和版本号。到访记录与食篮独立：移出食物不会抹掉到访，未到访食物不能加入，重复加入保持幂等。无效 JSON、未知 id、重复记录与未到访却已入篮的矛盾数据不恢复。

新键不存在时，从旧 `wuhan-breakfast-story.tour.v1` 迁移已收藏食物及年代；不把旧路线强加给新用户。旧记录只读，不覆盖。原 `/` 三店故事的 `wuhan-breakfast-story.save.v1` 保持独立。文件下载只写入实际选择的食物和实际到访地点，不能把没看的地方写成“全部完成”。

## 扩展与验收

给新店一个独立 `PlaceId`，在 `exploreContent.ts` 写世界坐标锚点、眼高停留点、章节和关联食物，再接入固定 socket。地图圆点由相机每帧投影，不要用百分比硬定位在截图上。手机地图要同时核验圆点位置和实际点击命中，不能只看 DOM 节点存在。

构建：`npm.cmd test`、`npm.cmd run build`。当前体验验收：`node tools/verify-explore.cjs`；基础街景和林记回归：`node tools/verify-street.cjs`。相关浏览器运行环境沿用 v6 的 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`、`SHARP_MODULE` 约定。

实际截图与报告位于 `verification-explore/`：21 项自由探索流程、23 项共用街景回归、36 项单元测试通过，封面另检查了三种视口。小视口检查不能代表实体手机 GPU 性能或扬声器听感。
