# 林记纸景样板：镜头、材质与今昔翻面升级

继续原有 `?sample=noodle` 页面，原三店剧情入口 `/` 不变。本版优先于 2026-10-01 交接文档中的相机、动画与材质描述。没有提交或推送远端。

## 本版要实际看到的效果

- 点击四件探索对象，镜头对准相应世界坐标并靠近。每件物品有独立取景范围和俯视角。手机按照横向可用空间自动调整距离。靠近后拖动围绕当前对象观察，点击“返回店铺全景”恢复。
- 今昔切换先退回全景，后墙向后让出旋转空间，再沿 Y 轴翻转 180°，最后回位。两面使用不同墙面素材：旧灰砖与斑驳墙皮 / 修补后的浅墙与灰绿瓷砖。木窗、架子的位置一致；柜台、店招、雨棚、人物与外带物件同步换代。
- 两代店主分别有原始表情、开口、闭眼三帧。选择人物后播放约八秒的开口节奏，可点“再聊一会儿”重播。平时偶尔眨眼。它是视觉对话动画，没有新增语音或音素同步。
- 太阳、冷色补光、局部暖灯和环境反射共同照亮材质。人物与墙面从不受光材质改为可接收光照的材质。仅保留一盏实时投影光，避免灯泡六面阴影增加移动端负担。
- 新生成的木纹用于梁、门、台面、柜板、小凳；添加浅浮雕纹理、磨损边缘、布棚织纹、石板倒角。罐子使用旋转曲面，杯子和叠碗有开口，蒸笼有环箍与接缝，屋瓦有曲面，门上有合页。

各材质类别共用凹凸纹理，程序生成的普通材质使用 256 像素贴图、木纹和布纹使用 512 像素贴图，避免每种颜色分配两张 1024 像素纹理。人物、食物与墙面的独立高分辨率插画仍使用原有尺寸。两代材质在加载阶段预热，减小切换中途编译着色器造成的停顿。眨眼按下一次触发时刻调度，低帧率也至少显示一帧闭眼。

## 复制到其他店时的代码位置

| 文件 | 负责内容 |
| --- | --- |
| `src/atelier/camera.ts` | 物品目标点、取景宽高、俯仰、朝向；手机距离适配 |
| `src/atelier/AtelierScene.ts` | 镜头插值、180° 翻墙时间线、年代状态、说话节奏、光照、资源生命周期 |
| `src/atelier/PaperWorkshop.ts` | 木纹、凹凸、粗糙度、陶釉、圆角、文字牌、人物表情材质 |
| `src/atelier/ShopDetails.ts` | 蒸笼、毛巾、门槛、合页、茶罐等独立几何 |
| `src/atelier/NoodleAtelier.tsx` | 选择物品驱动镜头，返回全景，手机滚动定位，重播对话动作 |
| `tools/verify-atelier-v2.cjs` | 本版桌面、手机、连续切换、表情帧、静止模式、原故事的实际浏览器验收 |

镜头不能只放大画布或修改 FOV：必须对准物品世界坐标。动画每帧将相机位置和观察目标一起插值。不要在其他帧循环中再覆盖这些参数。`data-camera-settled` 表示渲染循环已到达终点，验收应等待此值，不能仅睡眠固定毫秒数。

后墙两面文字与物件不能镜像：第二张图贴在背面，网格自身旋转 π，再由整块墙翻到正面。后墙翻动前退到后方，旋转包络不穿过柜台与人物。用户连续点击今昔时会取消上一条时间线并走向最新状态。减少动效模式直接切换终态。

人物原图与新帧保持相同画布尺寸。由于生成帧不保证身体逐像素一致，运行时只对脸部椭圆区域进行柔边切换，沿用原图身体与 alpha 轮廓，避免衣服、手和纸边跳动。每代人的脸部 UV 位置独立配置；扩展新人物必须重新校准。人物没有手臂骨骼或拌面动作。

## 素材与可重复制作

本次全部使用内置 `image_gen`，没有外部图库贴图。

| 新素材 | 用途 |
| --- | --- |
| `interior-present.webp` | 今日后墙 |
| `timber-grain.webp` | 模型旧木纹基础素材 |
| `keeper-speak.webp` / `keeper-blink.webp` | 林姐开口、闭眼帧 |
| `successor-speak.webp` / `successor-blink.webp` | 小林开口、闭眼帧 |

运行时文件位于 `public/assets/atelier/`；未覆盖原图位于 `docs/atelier/source-art/`。完整提示词在 `prompts-v2.json`，生成记录在 `generated-v2.json`。`tools/prepare-atelier-v2.cjs` 仅用 sharp 转为 WebP，不改变原图内容。旧版四张原图和提示词均保留。

运行 `npm.cmd run build` 更新 `dist/`，使用 `Start-Atelier.cmd` 直接预览。浏览器检查依赖 Playwright、Chromium、sharp，路径可通过 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`、`SHARP_MODULE` 设置，页面地址通过 `ATELIER_URL` 设置。新证据位于 `verification-v2/`；旧版 `verification/` 仅供前后对比。

## 扩展边界

该样板仍是风格化纸景，不是完整写实建筑：后墙中的部分物件属于绘制细节，人物与食物是有厚度的纸片。所有店主、店名与年代组合均为虚构创作，不能宣传成考据复原。没有新增烹饪小游戏、历史照片识别或远端 AI 服务。

接手时先看新截图与实机，再将视觉标准移植进原故事。不要用覆盖整目录的方式替换朋友已有工作，不要用样板收藏键替换原三店存档。移动设备真实 GPU、触屏与环境声音还需要最终展示设备实测。
