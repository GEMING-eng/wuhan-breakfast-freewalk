# v3 验收记录 · 2026-10-02

最终源码构建成功；原项目 22 项测试通过；`report.json` 的 17 项浏览器检查全部通过，页面异常与控制台错误均为空。

实际运行 Chromium + SwiftShader，桌面 1440×960，手机视口 390×844。通过用户已授权的独立 Playwright 浏览器操作，没有以素材图或静态 HTML 冒充页面截图。

检查覆盖：四件物品的相机取景、五种嘴型与独立眨眼、蒸汽所在画面的像素变化、面碗相对台面的正间隙、环境暂停后的静止画面、暂停时主动今昔翻转、四扇墙最终角度及界面主题、连续反向切换、手机无横向溢出与特写、说明弹窗、收藏重载、系统减少动效初值、原故事入口。

关键证据：

- `01-past-overview.png`：昔日界面与全景；`05-present-overview.png`：今日界面与修整后的墙。
- `02-bowl.png`：放大后的完整碗底、热气、台面接触与阴影。
- `03-face-0.png` 至 `03-face-2.png`：真实浏览器中的说话状态。
- `04-turning.png`：纸墙正在翻动的画面。报告记录到了暂停环境时的中间角度，四扇墙最后全部到达 180°。
- `08-mobile.png`、`09-mobile-bowl.png`：手机视口的全景与特写。

首轮发现低帧率下眨眼首帧权重为零，下一帧又越过闭眼时段。修复后，最终报告捕获了 0—4 五种嘴型和独立闭眼状态。`first-pass-report.json` 留作问题追踪，不能当作最终验收结果。

本报告没有验证实体手机 GPU 帧率、发热、触屏或扬声器。蒸汽像素检查覆盖整个场景区域，结合局部截图确认效果，不能单凭该数值推断蒸汽自身的粒子数量或性能。人物是视觉说话节奏，不含真实语音同步。实时纸景保留插画轮廓，不能称为 Blender 离线渲染。
