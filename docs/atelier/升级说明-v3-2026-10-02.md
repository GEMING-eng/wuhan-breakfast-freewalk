# 林记纸景 v3：今昔翻页、人物、热气与年代界面

本版继续 `?sample=noodle`。以下描述优先于 v1、v2 文档。原三店剧情 `/` 保留；没有推送 GitHub。先运行当前样板，再扩展其他店铺。

## 这次解决了什么

1. **今昔不再直切。** 旧代码把“暂停环境动效”同时当成“所有主动操作跳到终点”。现在暂停树叶、人物和蒸汽之后，主动切换今昔仍会播放约 3.75 秒的时间线：镜头回全景 → 雨棚收起、后墙后移 → 四扇纸墙依次旋转 180° → 店铺、人物和界面换代 → 纸墙、雨棚回位。每扇纸墙分别使用同一整图的四分之一，今日图贴在背面，不镜像。后移距离避开柜台和人物。连续反向点击从当前状态转向最后一次选择。
2. **人物各有六张表情来源。** 原始、开口、闭口、窄口、圆口、眨眼；本次新生成六张图片，两代人各三张。运行时仅替换嘴部和眼睑的柔边小区域，嘴型之间短暂插值；身体、脸型、鼻子、纸边保持原图。眨眼独立于嘴型，并保证低帧率下至少显示一帧闭眼。点击人物播放约八秒，点“再聊一会儿”重播。这是视觉说话节奏，没有语音和音素同步。
3. **热干面落在台面上。** 从纸片实际几何的最低点计算位置，保留 0.004 场景单位间隙，避免底部插进台面。相机目标随碗的新高度校准。
4. **热气从面上升起。** 五条透明噪声丝带在碗面上方独立扭动、扩散、淡出。热气不参与阴影和环境遮蔽，不产生矩形黑影。暂停动效保留当前蒸汽形态；展开纸层时隐藏。
5. **界面也属于这间店。** 昔日使用氧化红、旧纸、账册双线、搪瓷牌和印章；今日换成灰绿、浅纸和整理过的食单。页头、年代牌、探索按钮、正文、收藏、底栏同步变化。React 的“请求年代”和“画面当前年代”分开，实际换代发生在翻墙中段，避免界面先跳过去。
6. **光影更有体积。** 保留木纹、陶釉和布纹，重新平衡阳光、补光和环境反射；增加接触环境遮蔽、底座投影和四倍多重采样。透明边缘在线性光照中正确处理预乘 alpha，再执行显示变换，避免底座白边。阴影每帧只更新一次，环境遮蔽通道不重复计算阴影。

## 素材交接

- 新运行时素材：`public/assets/atelier/{keeper,successor}-{closed,ee,oh}.webp`。
- PNG 原图：`docs/atelier/source-art/`，连同旧版原图一并保留。
- 精确提示词：`prompts-v3.json`；生成记录：`generated-v3.json`。本次使用内置图像生成，没有借用外部图库。
- `tools/prepare-atelier-v3.cjs` 仅复制原图、编码 WebP。朋友的电脑没有原始生成路径时，直接使用包内 `source-art`，无需访问本机目录。
- AI 图像不保证逐像素配准，不能直接整张轮播。复制到另一位人物时必须重新核对嘴部与两只眼睛的 UV，实机放大观察闭口、开口、眨眼各状态。

## 运行与验收

普通预览：安装 Node.js 22.18+，双击 `Start-Atelier.cmd`，打开 `http://127.0.0.1:4173/?sample=noodle`。已包含 `dist`，不必先安装依赖。源代码修改后执行 `npm.cmd ci`、`npm.cmd run build`。

浏览器脚本使用 `PLAYWRIGHT_MODULE`、`SHARP_MODULE`、`CHROMIUM_PATH` 指定本机已有依赖，`ATELIER_URL` 默认为上述页面，运行 `node tools/verify-atelier-v3.cjs`。

最终报告与截图在 `verification-v3/`。`first-pass-report.json` 是修复眨眼前的失败记录，不是交付结果。`report.json` 是最终回归结果。`baseline-*` 是开发中的检查画面；最终截图以数字开头。构建成功与单元测试不能代替浏览器画面检查。

## 扩展时保留的约束

- 仍是有厚度的插画纸景。部分墙上器物属于绘制细节，人物和热干面仍是轮廓纸片，侧转范围受限。不能把它宣传成完整写实模型或 Blender Cycles 离线渲染。
- 实时 PBR、投影与环境遮蔽能增强模型体积，不能凭空补出插画中的三维结构。若要求任意视角和离线电影级效果，需要另做模型、灯光与烘焙资源。
- 软件浏览器验证覆盖功能和像素变化；最终手机的真实 GPU、温度、帧率、触屏和扬声器仍需展示设备实测。没有宣称手机满帧或音画口型同步。
- 店名、人物、对白与“约 1980 年代”组合是艺术创作，不能当作真实商户史料。
- 保留朋友已有工作。移植上述模块与资源前比较变更，不要用整目录覆盖。其他店的构图、色彩、纸偶和道具应独立设计。
