# 林记热干面 · 精细纸景样板

**2026-10-02 v3 更新：先读 [今昔、人物、热气与年代界面升级](升级说明-v3-2026-10-02.md)。** 墙面依次翻转、暂停后仍可切换、人物六张表情来源、热气与面碗位置、随年代变化的完整界面和接触光影均已更新。最新浏览器证据在 `verification-v3/`，本页下方是第一版基础说明；发生冲突时以 v3 升级说明为准。

## 先打开样板

1. 阅读本文，并检查你当前工作区的 `git status`，保留已经完成的剧情与其他店铺工作。
2. 安装依赖后运行开发服务，打开 `/?sample=noodle`。示例：`http://127.0.0.1:5188/?sample=noodle`。
3. 先观看昔日、今日、近景、纸层展开四个状态，再点击店主、面碗、酱罐、小凳。`verification/` 中是本机实际浏览器截图，可以对照。
4. 确認样板可运行后，再将同一套画风扩展至豆皮铺、面窝摊。原来的故事入口仍为 `/`。

交付完成的对象是一个独立、可运行的店铺样板。它尚未替换原故事中的热干面店，也尚未接入原故事的完成记录。样板独立保存一条记忆，原来的三店剧情与存档保持原状。

## 画风的核心

“旧纸上的汉口清晨”：暖白纸底、砖红招牌、靛蓝旧木门、灰绿屋瓦、深色内堂，采用水粉笔触和纸张颗粒。视觉重点是店主的脸、面碗、手边的酱罐；其他纹理和器具提供生活感。

这是基于武汉饮食文化创作的虚构街巷。林记、林姐、小林和两代传承关系均为创作。昔日约 1980 年代、今日为当代情境；建筑与器物组合不构成对某一真实街道或精确年份的复原证据。后续引入具体史实，沿用原项目 `src/content/sources.ts` 的资料核查流程。

| 层次 | 本样板做法 | 扩展标准 |
| --- | --- | --- |
| 远景/内堂 | AI 辅助生成的墙面印刷图，挂在独立后板上 | 保留空间暗部；选择有内容的窗、墙、架，而非大面积统一黄色 |
| 建筑 | 真正的纸板几何、侧墙、折叠门、屋檐、瓦片 | 三店应有不同轮廓和工作台组织，不只是换颜色 |
| 人物 | 透明插画，读取 alpha 提取外轮廓，再挤出约 0.035 单位厚度 | 成年人的比例、明确姿态、有使用痕迹的衣服；让脸在普通和近景都可见 |
| 食物 | 单独的透明面碗纸片，独立于人物和背景 | 食物要有辨识度与细节；不能把整幅店面当食物素材 |
| 器物 | 立体纸制酱罐、搪瓷杯、筷子筒、碗堆、小凳 | 优先做剧情旧物，其次做陪衬；保留明确前后层级 |
| 光影 | Three.js 方向光、半球光、局部灯泡与实时阴影 | 柔暖晨光下仍保留靛蓝和灰绿，避免整屏泛黄 |
| 动态 | 蒸汽上升淡出、招幌轻摆、叶簇轻摆、人物微呼吸、视角缓动 | 动作幅度克制；不要让整幢建筑同步晃动 |
| 界面 | 侧边街巷手记、画内小编号、轻量今昔开关 | 文字不要压住人物和食物，完整交互可用按钮与键盘完成 |

内堂的货架、挂具等细节目前包含在墙面印刷图中，并非每件都独立建模。前方门框、雨棚、柜台、纸偶、面碗、旧物和枝叶有真实深度。继续精修时可将某一需要互动的内堂物件拆成新层。

## 今昔共用同一空间

两套年代状态使用同一相机、主体建筑与永久物件坐标。

| 保持不动 | 昔日 | 今日 |
| --- | --- | --- |
| 木窗、旧门、屋瓦 | 砖红店招 | 浅纸色新店招 |
| 木柜台主体 | 磨旧木台面 | 浅灰绿易擦洗台面 |
| 酱罐、搪瓷杯、蓝花碗 | 红色雨棚 | 灰绿与暖白雨棚 |
| 小凳和修补部位 | 林姐纸偶 | 年轻接班人小林纸偶 |
| 原有格局 | 旧开门挂牌 | 新营业牌、堂食外带牌、纸袋 |

让用户看得出“同一个位置，出现了新的生活”。后续其他店铺每家至少设计 3 个看得见的年代变化、2 个不变的传承物件。替换材质颜色只是其中一项。

## 代码定位

| 文件 | 职责 |
| --- | --- |
| `src/main.tsx` | 仅增加 `?sample=noodle` 的懒加载分支，原故事入口保留 |
| `src/atelier/NoodleAtelier.tsx` | 样板页面、今昔与旧物选择、声音、减少动效、记忆保存、说明对话框 |
| `src/atelier/AtelierScene.ts` | 单一 renderer、店铺构建、相机、纸层位置、微动效、年代物件、热点投影、资源清理 |
| `src/atelier/PaperWorkshop.ts` | 纸板/轮廓几何、纹理与字体、alpha 轮廓、同材质静态几何合并 |
| `src/atelier/content.ts` | 两个年代的全部样板文案与类型 |
| `src/atelier/atelier.css` | 以 `.atelier` 为作用域的样板布局；手机上方纸景、下方阅读区 |
| `public/assets/atelier/*.webp` | 运行时素材；保留人物和食物的透明通道 |
| `docs/atelier/source-art/*.png` | 未覆盖的生成原图，可作为以后精修或编辑输入 |
| `docs/atelier/prompts.json` | 本次全部内置 image_gen 生成提示词与素材来源 |
| `tools/verify-atelier.cjs` | 独立 Playwright 浏览器验收；截图和报告写入本目录的 `verification/` |

`PaperWorkshop` 所有几何、材质、纹理都有生命周期所有权；销毁页面时释放。合批只在静态、同一父层、同材质的网格之间进行。人物、图像纸片、蒸汽与动态层级保留独立身份，避免合并后无法动或无法替换。

目前热点是世界坐标投影的 HTML 按钮，样板通过限制观景角度与确定构图保持可见；不是自由漫游系统，也没有把每个渲染物件绑定拾取。整合进原故事时可继续使用原有 `Picking.ts` 遮挡检查和三维命中逻辑。

## 将样板整合到三店故事

1. 在原故事的 `SceneStage` 生命周期内使用店铺专属构建器，保持只有一个 renderer。不要同时叠加旧舞台与样板舞台。
2. 将 `content.ts` 的创作文字按需要映射到原 `story.ts`，继续保留“观察后解锁追问、末句完成后记忆入账”的规则。
3. 把样板的 `jar`/`stool` 等键映射到原故事旧物 ID；不要让样板的独立收藏键代替三店完成状态。
4. 给豆皮铺设计宽锅台、切分工具与摊面动作；给面窝摊设计临街油锅、沥油架与开放摊口。共享材质与纸层工具，分别设计店铺轮廓、布局和叙事物件。
5. 为每家店分别设计昔日/今日状态；对齐永久旧物的坐标、尺度和镜头。
6. 最后更新相片入口：从同一最终纸景渲染定格，避免相片与进入后的店铺不一致。

每一步完成后都实际打开对应页面，观察人物是否被雨棚遮挡、热区是否跟着镜头、阅读区是否挤压场景。只有构建通过不足以认定美术完成。

## 生成与导入素材

本次使用内置 `image_gen`，没有 API Key 或额外图像 API 配置。四个文件分别独立生成：内堂、林姐、小林、面碗。PNG 原图保留；WebP 是质量 92、alpha 质量 100 的格式导出，显示文件合计约 2.17 MB。

可读取 `prompts.json` 复用完整提示词。新人物采用相同纸面、色板、正面略转侧的视角；背景只生成内堂印刷层，外部建筑几何在程序中搭建。独立物件生成时要求透明背景、完整轮廓、没有外部投影和蒸汽。中文店招由程序排字，保证可读。

轮廓提取按 alpha 阈值采样左右边界，适用于本样板连续外轮廓。复杂镂空或需要分开摆动的手臂、工具应单独出素材和轮廓。当前人物只有微呼吸，没有手臂分层，也没有实时拌面动作。

## 验收与边界

读取 `verification/report.json` 查看本次实际自动交互结果；对应 PNG 是运行中的浏览器截图。原项目 22 项测试已通过。开发页验证包含桌面 1440×960 与手机模拟 390×844；非真实手机实测。

一套画布；显示更新上限 30fps；像素比上限 1.5；页面隐藏暂停。静态几何合并后，桌面场景记录约 397 次绘制（含阴影），实际次数以报告为准。尚未验证真实手机温升、持续帧率、Safari 或触觉反馈。

声音沿用原项目合成环境声，默认关闭，不是街头实录或真人配音。当前没有验证真实扬声器听感。构建仍有 Three.js 超过 500 KB 的体积提醒。

扩展店铺的完成条件：昔/今两态、近景、旧物互动、手机布局全部截图检查；人物脸部清晰、面碗可辨、无热区错位或横向溢出；动效开关有效；页面退出释放资源；原故事流程与存档测试通过。
