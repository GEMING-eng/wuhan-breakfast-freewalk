## 图像与记录方法

`ui-*.png` 是浏览器内 html2canvas 对当时页面的捕获，包含实际 WebGL 画布和 HTML 界面，排除了开发验收面板；已结合内置浏览器原生截图目视复核。配套 JSON 记录实际 `innerWidth/innerHeight`、DPR、节点、观察/完成状态与相机名称。

`paper-*.png` 是同一 WebGL 画布的直接导出，不包含 HTML 界面。配套 JSON 记录实际画布像素尺寸、相机位置/目标、几何类型、厚度、局部与世界变换、交互锚点、绘制次数和三角形数。纸景的光影由 Three.js 灯光生成。

`paper-street-portal_*.png/json` 是正常照片展开时的三维关键帧。比较相机位置、纸层世界变换与 `portal.depth`，可验证真实三维深度展开；这些全画布帧不包含 HTML 相纸边框/裁切，不能用来单独判断完整过场的所有视觉细节。

## 性能与资源实测

公共本地文件 18 件，总计约 2.93MB；包括约 2.65MB 的原创 WAV。完整 `dist` 未压缩约 3.91MB，已按 Three/React/GSAP 分块。程序纹理不需要额外远程图像。

同一内置浏览器检查中，热干面场景普通模式记录约 398 次绘制，低性能模式约 134 次；视口/相机不同时数值会变化，以配套 JSON 为准。默认更新上限 30fps，低性能模式 24fps，DPR 上限分别为 1.5 和 1；隐藏页面暂停画布更新，低性能模式关闭阴影与蒸汽，仍保留三维几何。
